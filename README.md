# CrossApp

Наскрізний проєкт з крос-платформного програмування.

## Предметна область

**Бібліотека**

### Сутності

- Book — книга
- BookCopy — примірник книги
- Reader — читач
- Loan — видача книги

### Призначення

Застосунок призначений для обліку видач примірників книг читачам і їх повернень.
